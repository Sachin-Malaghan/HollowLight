Privacy policy

Last updated 29 September 2026

The short version

HOLLOWLIGHT does not collect, store, share or sell any personal information. There are no accounts, no ads, no analytics and no tracking of any kind, in the game or on this website.

What the game stores

The game saves a small file on your own device with your progress (which levels you have reached, your best times) and your settings (sound, music, touch controls, film grain, reduced flashing). This file never leaves your device. Deleting the game deletes it.

Network access

The game does not need an internet connection and does not send anything over the network.

Permissions

On Android and iOS the game asks for no special permissions: no location, camera, microphone, contacts or photos.

Children

Because no personal information is collected from anyone, none is collected from children.

This website

This site uses no cookies, no analytics and no third-party scripts or fonts. Your browser loads only the files that make up these pages. The host that serves the pages may keep standard server logs (such as IP addresses) for security, as all web hosts do.

Changes

If this ever changes, this page will be updated before the game is, and the date above will change.
